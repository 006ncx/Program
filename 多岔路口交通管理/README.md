# 多岔路口交通管理 —— 用图着色求最少信号相位

## 1. 问题

题图是一个五岔路口，其中 **C、E 为单行道**，共有 **13 条可通行路线**。
有的路线不能同时通行（如 E→B 与 A→D），有的可以同时通行（如 A→B 与 E→C）。
问如何设置交通灯管理该路口的车辆通行。

## 2. 13 条路线是怎么来的

由题面例子反推单行道方向：

- E→B 存在 ⟹ **E 是进口道**（车流只能由 E 驶入路口）；
- E→C 存在 ⟹ **C 是出口道**（车流只能由路口驶出到 C）。

于是进口道 = {A, B, D, E}，出口道 = {A, B, C, D}，去掉同一条路的"掉头"，共 3 + 3 + 3 + 4 = **13 条**。

## 3. 数学建模：顶点着色

- **顶点**：13 条通行路线（车流）；
- **边**：两条路线不能同时放行就连一条边，得到**冲突图 G**；
- **相位**：G 的一个**独立集**（其中任两条路线都不冲突，可同时亮绿灯）；
- **目标**：用最少相位覆盖全部路线 ⟺ 求 G 的**色数 χ(G)** 并给出一个最优着色。

所以：**最少相位数 = χ(G)**，**分相方案 = 一个最优着色**。

## 4. 冲突判据

我国为右侧通行，采用三条判据：

1. 同一条进口道分出的两条路线（**分流**）—— 不冲突；
2. 驶入同一条出口道的两条路线（**合流**）—— 冲突；
3. 其余情形 —— 两条路线的**行驶轨迹在路口内部相交**则冲突。

轨迹按圆弧看待：从进口道断面上（本车方向的右侧）出发、切于车头方向，
在出口道断面上（本车方向右侧）终止、切于出口车头方向；两段圆弧在内部真正相交即冲突。
按此得到 13×13 冲突矩阵（共 35 对冲突），程序中直接以常量表给出。

> 说明：判据 2 是可以商量的一个建模选择（单车道出口时才必须算冲突）。
> 若把它去掉（只算轨迹相交），冲突对由 35 降为 20，**色数仍然是 4**，结论不变。

```bash
gcc -O2 -o intersection_signal intersection_signal.c
intersection_signal
```

Visual Studio / Dev-C++ 新建工程加入该源文件直接编译即可。
Windows 下程序会自动执行 `chcp 65001` 以便正常显示中文。

## 6. 程序流程

1. 打印 13 条路线与 13×13 **冲突矩阵**；
2. 用**回溯法**求色数：k = 1, 2, 3, … 依次判断能否用 k 种颜色给冲突图着色，
   第一个可行的 k 就是 χ(G)，同时得到一个最优着色；
3. 打印**分相方案**（每个相位放行哪些路线）；
4. **自检**：同一相位内两两不冲突；再验证少于 χ(G) 个相位无解。

## 7. 运行结果

```
色数 chi(G) = 4  ->  最少相位数 = 4

分相方案：
  第 1 相位： A>B A>C A>D B>A   （4 条路线）
  第 2 相位： B>C B>D E>A   （3 条路线）
  第 3 相位： D>A D>B D>C E>D   （4 条路线）
  第 4 相位： E>B E>C   （2 条路线）

检验通过：每个相位内部两两不冲突，13 条路线全部覆盖，且少于 4 个相位无解。
```

**结论：该五岔路口最少需要 4 个相位。**
